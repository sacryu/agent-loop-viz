# 隐私说明

Agent Loop 把你的 Claude Code 对话画出来：只给你自己看，或者给你和朋友（一个星系群）看。这份说明讲清楚**什么会离开你的电脑、谁能看到什么**。

## 一句话的承诺

**除了你自己的电脑，任何服务器都只拿到匿名的类别、耗时和一段它解不开的密文。**

唯一会把数据发出你电脑的代码是 [`plugin/hooks/report.mjs`](../plugin/hooks/report.mjs)，一个不依赖任何包、不经编译、可以直接读的脚本。下面说的每一条都能在那个文件里找到。

## 三种用法

| 用法 | 服务器在哪 | 附件 | 谁能看 |
|---|---|---|---|
| 本机 | 你的电脑，`127.0.0.1` | 明文（数据不出电脑） | 你自己 |
| 自己部署 | 你的服务器 | 密文 | 有邀请链接的人 |
| 别人托管 | 别人的服务器 | 密文 | 有邀请链接的人 |

「本机」只认主机名严格等于 `127.0.0.1`、`localhost`、`::1` 的地址。填一个长得像本机的公网地址，也只会按「别处」处理。

## 白名单

脚本**不是**从原始数据里删掉敏感字段，而是只挑出允许的几个字段，重新拼一条事件。Claude Code 以后新增的任何字段，默认都不会被发出去。

## 分享档位

在插件设置的 `share` 里选。只由你的插件决定，服务器没法要求多传。

| 档位 | 发出去的 |
|---|---|
| `anonymous`（档位 0） | 只有匿名字段（见下表），没有附件 |
| `summary`（档位 1） | 匿名字段 + 小附件：星系的名字（你在设置里填的）、项目目录名（最后一段）、对话标题（Claude Code 给这段对话起的标题，从本机的会话记录里读；还没起好时用你第一句话的开头）、每一步的真实工具名和对象（文件路径的最后两段、命令的前 60 个字符、搜索词、网站的主机名、子 agent 的说明……）、报错的第一行、子 agent 的真实类型名、每次回答的最后一句 |
| `full`（档位 2） | 再加上大附件：你输入的整句话、工具完整的输入和输出、完整的回答、完整的报错、通知的文字。单个大附件超过 32 KB 时把长字符串截短；Edit、Write 回应里的整份原文件不发 |
| `auto`（默认） | 本机是 `full`，别处是 `summary` |

## 匿名字段（每一档都有）

| 处理 | 内容 |
|---|---|
| **加盐哈希后发出去** | 会话编号、项目目录、子 agent 编号、输入编号、工具调用编号、子 agent 的类型（只用来配对）。哈希是 `sha256(盐 + 原值)` 的前 16 个十六进制字符。盐是你电脑上随机生成的，**从不上传** |
| **归类后发出去** | 工具名归成固定的 11 类（读文件、改文件、搜代码、跑命令、上网、子 agent、问你、确认计划、记账、外部服务、其他）；子 agent 类型只保留几个内置的名字，其余记成 `custom`；API 报错归成 6 类；你输入的话只剩一个布尔值：是不是后台任务跑完的通知 |
| **原样发出去** | 事件名、你电脑上的时间戳、工具耗时、是不是被打断、通知的类型（只限几个已知的值）、会话是怎么开始的、回合结束时还在跑的后台任务个数、模型名（只认 Claude 的模型名格式，从会话记录末尾读出来）、上下文和累计输出的 token 数（两个整数，从会话记录里的 usage 加出来）、到目前为止的圈数和步数（两个整数：会话记录里主对话回答了几次、调用了几次工具，服务器重启过也能接着累计） |

档位 0 的事件长这样：

```json
{"v":2,"level":0,"ev":"PostToolUse","ts":1795203854777,"sid":"b3ddeaef76a7636d","proj":"5e64a58ecb6cb041","prompt":"6a578d3fbd10188f","tool":"4b12a22b6ebc8412","kind":"shell","duration_ms":576}
```

## 加密

邀请链接的样子：`https://<服务器>/#k=<K>`。`K` 是 32 字节随机数。`#` 后面的部分浏览器不会发给服务器，插件也只在本机用它。

从 `K` 用 HKDF-SHA256 派生出两样东西：

| | 给谁 | 用途 |
|---|---|---|
| 口令 | 发给服务器（请求头 `X-Group`；浏览器连上以后发 `join`） | 上传和观看都要带它。星系群编号 = `sha256(口令)` 的前 32 个十六进制字符，服务器自己算，不需要保存任何星系群的记录 |
| 内容密钥 | **永不离开你的插件和看的人的浏览器** | 用 AES-256-GCM 加密、解密附件 |

服务器知道口令，但口令推不回 `K`，也推不出内容密钥。每个附件加密时，把 `协议版本|槽|对话|键`（比如「这是哪一次工具调用的输入」；名片是「哪个星系的哪个项目」。名片在会话开始时发一次，每次提问再补发一份同样的内容，好让服务器重启以后补回项目名）作为附加校验数据，浏览器解密时用它自己知道的位置来验：服务器没法把一步的附件挪到另一步上，也没法把你的名字和项目名安到别人的星系上。唯一例外是「这一轮在问什么」和「回答」：浏览器不知道每一轮的编号，服务器可以把同一个对话里不同轮的这两样调换。

发往别处时：附件**必须**加密；没有邀请链接（没有密钥）就**什么都不发**；服务器收到明文附件直接拒绝（协议里就不允许这个字段）。

附件里出现的邀请密钥（`k=` 后面 43 个字符）在加密之前一律抹成 `k=…`：接入或换群时那几行命令、你粘进对话的邀请链接、回答里复述的链接都带着密钥，不抹掉的话会跟着「完整」档位发进原来的群，那个群里的人就能拿它进你的新群。

## 本机模式

本机模式下附件是明文，所以服务器只认本机：请求的 `Host` 必须是 `127.0.0.1`、`localhost` 或 `::1`（挡住 DNS 重绑定），浏览器页面的 `Origin` 必须也是本机。别的网站在你浏览器里连 `ws://127.0.0.1:4317` 会被拒绝。

## 服务器仍然能看到的

- 匿名字段：你什么时候在用、同时几个对话和项目、每一步的工具类别和耗时、是否出错、有没有在等你授权。
- 哪些星系在同一个星系群里。
- 你的插件版本：每次上报都放在请求头 `X-Agent-Loop-Plugin` 里。服务器记下哪些星系的插件旧了（30 分钟没再上报就忘掉），只告诉同一个星系群里的人，页面据此提示更新。
- 附件的大小（能大致猜出一步的输入输出有多长）。
- 没有口令的人什么都看不到：`/healthz` 在非本机的服务器上只答「活着」，不给星系数、会话数。
- IP 地址：只在内存里用于限流（IPv6 按 /64 算），不保存、不显示、不打日志。部署用的反向代理（[`deploy/Caddyfile`](../deploy/Caddyfile)）不写访问日志。

所有状态只放在内存里，不写盘，重启即清空。会话结束就移除，它的大附件一起清掉；每个星系的大附件最多占 8 MB，满了丢最旧的。

## 信任边界

不能把「服务器看不到」说过头：

- **页面的代码是服务器给的。** 浏览器里解密用的代码来自你打开的那台服务器。托管方如果作恶，可以换一份会偷密钥的页面。防的办法是用自己部署的服务器。
- **邀请链接就是全部权限。** 泄露了就等于把人请了进来。现在还不能踢人、换密钥，只能新建一个星系群。
- **退出星系群要在插件里做。** `/agent-loop:leave` 在本机记下这个群（以后哪个会话都不再往它发），再告诉服务器（`POST /v1/leave`，带安装密钥和口令）把你的星系连同存着的大附件马上移走。服务器只接受星系移走自己：拿着邀请链接的人移不走别人。退出以后插件在浏览器里打开 `<服务器>/#left=<群编号前 16 位>`（不带密钥；`#` 后面的部分不发给服务器）：页面里存着的是这个群的密钥就清掉，连同「我的星系」的记号，指纹对不上的不动（别人发来的 `#left=` 链接清不掉你看的另一个群）。页面上的「清除缓存」只让那个浏览器忘掉密钥、不再看，不会让你的星系停止上报（页面没有你的安装密钥）。
- **建群也在插件里做。** `/agent-loop:create` 在你的电脑上生成密钥，用 `claude plugin configure --values-stdin` 从标准输入存进 `server_url`（不进命令行参数、shell 历史和对话），再带着密钥在浏览器里打开这个群，邀请链接只在那里出现。建群前问服务器的 `/healthz` 收不收新群、是什么版本，这一步不带任何口令。然后先把正在跑的会话报到新群，服务器收下了才存 `server_url`：被拒（群数满了、这个网络建群太多）时你原来的设置不动。
- **别人发来的链接不会把你悄悄换到另一个群。** 浏览器里已经存着一个星系群的密钥时，再打开带着另一个密钥的链接，页面先问你要不要换，并摆出两个群的指纹（星系群编号开头的 16 个字符）；不点「换过去」，原来的密钥不动。页面右上角一直显示当前这个群的指纹的前 8 个字符，群里每个人看到的都一样。
- **同一个星系群里的人互相完全可见**（到各自选的档位为止）。
- **`/galaxy` 命令**：命令的输出会进对话、发给模型，所以它只打印不带密钥的网址；带密钥的网址由插件直接交给浏览器打开。
- **接入命令（`report.mjs --welcome`）**：邀请面板里那段话的最后一行，由 Claude 在终端跑。它把你正在用的这个会话作为一次「会话开始」报上去（和 hook 发的同一种事件、同样的档位和加密），为此读本机的几样东西：Claude Code 给命令的会话编号、这个会话的会话记录（项目目录、模型名、标题、圈数、步数，和 hook 读的一样）、用户级 `settings.json` 里插件的 `share` 和 `name`、`installed_plugins.json` 里装着的插件版本。它的输出同样会进对话，所以也不带密钥；带密钥的网址直接交给浏览器打开。
- **用 `http://` 打开时**（比如内网的测试服务器），连接本身没有加密，页面可能在路上被人改掉；附件仍然是端到端加密的。页面上会提示「连接没有加密传输」。

## 本机的文件

插件的数据目录（`~/.claude/plugins/data/…`）里：

- `identity.json`：`secret`（32 字节随机数，上传的凭证，放在 `Authorization: Bearer …` 里）和 `salt`（只用于本机哈希，从不上传）。你的星系编号是 `sha256(secret)` 的前 32 个十六进制字符。想换一个身份，删掉它就行。
- `server.json`：最近一次用的 `server_url`（可能带着邀请链接），给 `/galaxy` 命令用。权限 0600。
- `left.json`：用 `/agent-loop:leave` 退出过的星系群编号（公开的那个编号，不是密钥），这些群插件不再往里发。`/agent-loop:rejoin` 去掉。权限 0600。
- `moved.json`：用接入命令（`--welcome`）换群时换走的旧目标（旧星系群的编号，或者旧的服务器地址；不是密钥）。已经开着的会话在 `/reload-plugins` 以前还拿着旧的 `server_url`，它们的 hook 看到旧目标在这里就不发，免得你的星系在新旧两个群之间来回搬。新开的会话还拿着旧值时（说明你又改回去了）去掉。权限 0600。
- `hello.json`：已经让 Claude 讲过说明的星系群编号（公开的那个编号，不是密钥）。第一次在一个星系群里说话时，插件把一段说明（服务器地址和指纹、会分享什么、怎么加密、怎么改名字和分享多少）作为上下文交给 Claude，让它告诉你，然后记在这里，同一个群不再讲。权限 0600。
- `status.json`：最近一次发送的结果（服务器地址，不含 `#k=`；HTTP 状态码或「连不上」）。会话开始时插件据此判断要不要在 Claude Code 里提示「没有上报」，只在本机读，从不上传。权限 0600。
- `sweep.json`：上次替别的会话补发 SessionEnd 的时间，和补发过的会话编号（Claude Code 的原始会话编号，只在本机，从不上传；两小时以后去掉）。会话开始、你说话时，插件最多每分钟看一次 Claude Code 自己登记的正在跑的会话（`~/.claude/sessions/`）和插件报过的、最近两小时动过的会话记录（从下面 `usage/` 缓存里记着的会话记录路径找，看记录文件的修改时间，不读内容）：已经结束、却没把 SessionEnd 送到服务器的会话（关窗口、进程崩了、旧版本插件、网络断了），替它补发一条，不然它在页面上要挂两个小时。补发的这条和那个会话自己会发的完全一样，只有加盐哈希后的会话编号，没有附件；服务器上没有这个会话时什么都不做。登记里找不到正在跑的这个会话、或者登记读不懂时不补发。权限 0600。
- `usage/<哈希后的会话编号>.json`：每个会话的会话记录在哪里、读到了哪里、到那里为止的 token 数、圈数、步数、对话标题和最后一个模型名，下次从那里接着读，不用每次把整个记录读一遍。只在本机，从不上传；30 天没动过的在会话开始时删掉。权限 0600。

`server_url` 是敏感设置：存在系统的凭据存储里，不在 `settings.json` 里。

## 测试

[防泄漏测试](../test/plugin-leak.test.ts)为每种事件造一份完整的假数据，在每个字符串字段里（包括路径、命令、输入的话、报错、以后可能新增的字段）都塞进唯一的标记串，然后检查：

- 档位 0 的输出里一个标记串都不出现，并且严格符合协议（不允许多余字段）；
- 发往别处时，三个档位的请求里没有任何标记串以明文出现；用密钥解开附件后，出现的标记串和上面的表完全对应（比如路径里的用户名、hook 数据里的会话标题字段、以后新增的字段，哪一档都不会出现）；
- 发往别处却没有邀请链接时，脚本一个字节都不发。

这些检查既直接调用脚本里的函数，也把脚本当成进程跑一遍、截下它真正发出的请求。

## 不想上报的时候

把 `share` 设成 `anonymous`，或者停用插件：`claude plugin disable agent-loop@agent-loop`。还不支持「某些项目永远不上报」。
