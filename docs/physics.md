# 画面里的物理

Agent Loop 用天文来表达 Claude Code 的会话。这里记下每个设定对应的物理或天文现象，以及哪里做了夸张。
原则：每个设定都要说得出它在物理上是什么；时间可以压缩、幅度可以放大，但方向不能和物理相反。

## 三层画面各是什么

| 画面 | 物理上是 | 对应 |
|---|---|---|
| 星系群 | 几个到几十个被引力束缚在一起的星系（比如银河系所在的本星系群） | 互相可见的人：自己，或者自己和朋友 |
| 一团光 | 一个星系 | 一个人（一个安装） |
| 点进去之后 | 这个星系里的一个**行星系** | 中心恒星 = 模型；行星 = 对话；轨道 = 项目；卫星 = 后台任务 |

点进去看到的是行星系而不是星系：中心一颗恒星、行星绕着转、行星自转、带卫星和环，这些都是行星系的特征。

## 星系群

| 设定 | 物理 |
|---|---|
| 几个星系绕着中间一个看不见的点慢慢转 | 星系群里的成员被引力束缚，绕共同的质心运动 |
| 里面的星系转得快，外面的慢，角速度和半径成反比 | 群里的质量大多在暗物质晕里。晕的转动曲线是平的（各处的环绕速度差不多），所以角速度 ∝ 1/半径；不是开普勒的 半径^-1.5（那是质量集中在中心的时候） |
| 群的中间一层极淡的冷光，成员越多越亮 | 群内的热气体：被群的引力势阱加热到上百万度，X 射线波段很亮，可见光里极淡 |
| 轨道面斜着看，竖直方向压扁 | 我们看到的是轨道在天球上的投影 |
| 星系比宇宙网里画得大 | 群里的星系彼此很近：银河系和仙女座只隔二十几个银河系的直径 |

夸张的地方：真实的星系群转一圈要几十亿年，这里最外面一圈 15 分钟。

星系超过约 50 个时（比如 `?demo&n=2000` 测性能时）换成下面的宇宙网。

## 宇宙网（星系很多时）

| 设定 | 物理 |
|---|---|
| 星系聚成团、排在纤维上，中间是大片空洞 | 宇宙网：星系约一半在纤维上，一部分聚成星系团，空洞里只有零星几个 |
| 没有居中的光；有星系聚着的团中间一层极淡的冷光，成员越多越亮，空位置不发光 | 宇宙学原理：宇宙没有中心。团中间的光是团内光（被潮汐从成员星系里剥出来、在星系之间游离的恒星）和热气体，没有成员星系就没有它 |
| 越活跃越亮 | 星系的亮度跟恒星形成率相关 |
| 会话越多光团越大 | 星系的尺寸和光度相关 |
| 光团压扁、带转角；核心不压扁 | 倾斜的星系盘投影成椭圆；中央核球接近球形 |
| 珊瑚色 = 在干活 | 恒星形成区的 Hα 发射，照片里是粉红到橙色 |
| 只有核心会闪 | 活动星系核。整个星系有十万光年宽，不可能几秒内整体变亮（光从一头走到另一头就要十万年），能快速变化的只有很小的核心 |
| 出错：核心旁一个红点，先爆亮再暗成一个常亮的小点 | 超新星：星系里突然出现的点光源，光变曲线快升慢降，留下遗迹 |
| 背景：三层远处的点，越远越多、越小、越暗、越红；最近一层有些是压扁的小光斑；分布成团而不是均匀撒开 | 深空场：更远处的背景星系。越远红移越大；近一些的能分辨出椭圆的星系盘；背景里也有宇宙网，所以成团 |
| 背景整体缓缓漂移，近的层漂得快、远的层漂得慢 | 视差：我们自己相对背景在动（银河系相对宇宙微波背景约 600 km/s），近的位移大 |
| 背景里偶尔一个点对称地亮起来再暗回去 | 引力微透镜：前景天体从背景点前面掠过，光被弯折聚焦，亮度曲线前后对称（Paczyński 曲线） |
| 背景里偶尔一个星系旁多出一个点，很快变亮再慢慢暗下去，越来越红 | 遥远的超新星：快升慢降，爆发后的物质在冷却所以变红 |
| 背景不闪烁 | 闪烁是地球大气造成的，太空里看不闪 |
| 星系名「ALC 1342+27」 | 星表编号：赤经 13 时 42 分、赤纬 +27°。赤纬按天球面积均匀取 |
| 「你的星系」外的虚线圈 | 寻星图上标目标的圈 |
| 定位特效：密度波，波峰扫到哪、哪里被推开并变暗 | 重子声学振荡（从密度高处推出去的纵波）+ 萨克斯-沃尔夫效应（波峰处势阱更深，光爬出来损失能量，显得更暗） |

夸张的地方（宇宙网和背景）：星系转动、密度波、背景的漂移、微透镜（真实的要几天到几个月）、超新星（真实的要几周）都压缩到秒级；密度波的位移和变暗放大到看得见（真实的 BAO 早已冻结，而且幅度极小）。

## 行星系

| 设定 | 物理 |
|---|---|
| 中心是一颗恒星（模型），周围一大片很淡的光，颜色跟着恒星 | 恒星和被它照亮的尘埃 |
| 恒星是一个会自转的球：表面的花纹转到边上被压扁、变暗，再转到背面去 | 自转。花纹按球面上的 3D 位置生成，所以压扁和遮挡是几何上自然出现的 |
| 自转轴垂直于行星的轨道面；轨道面倾斜多少，球就倾斜多少；拖着行星系转，恒星跟着转 | 行星系是从同一团旋转的气体盘里形成的，恒星的自转和行星的公转同向、同一个面（太阳的自转轴和黄道面只差 7°） |
| 赤道转得比两极快：不同纬度的黑子转得不一样快 | 较差自转：恒星是气体，不是刚体。系数取自太阳（赤道约 25 天一圈，两极约 35 天）。米粒只活几分钟，看不出较差自转，所以表面纹理整体按一个速度转 |
| 表面细细的一格一格，慢慢在变 | 米粒组织：对流把热气体顶上来（格子中间亮），冷了从缝里沉下去（缝暗） |
| 黑子成对出现，领头的（自转方向在前的）更大、更靠赤道 | 活动区是一段浮出表面的磁力线，两头是极性相反的一对黑子；领头的更靠赤道是乔伊定律 |
| 黑子会冒出来、慢慢缩小、散掉；大的活得久；后面那个先散；周围的亮斑比黑子留得久 | 黑子的面积很快长到最大，然后大致按固定速率缩小，所以寿命和最大面积成正比（Gnevyshev–Waldmeier 规律）；跟随黑子通常先碎掉；光斑（谱斑）在黑子消失后还能留几周 |
| 黑子时多时少，有时一个都没有；新黑子冒出来的纬度从约 30° 慢慢移向赤道 | 恒星的活动周期（太阳约 11 年）：极大期黑子多，极小期可能连着几天一个都没有；新黑子的纬度随周期移向赤道是斯波勒定律（画出来就是「蝴蝶图」） |
| 每个星系的恒星黑子不一样；同一个星系、同一时刻，谁打开看到的都一样 | 每颗恒星有自己的活动周期和黑子。黑子由星系编号和真实时间算出来，不是每次打开时随机的 |
| 黑子周围的亮斑，靠边才看得清 | 光斑：磁场让那里的气体更透明，看到的是更深、更热的一层。在盘中心它和周围一样亮，到了边上对比才明显 |
| 恒星的球边缘比中心暗、也更红 | 临边昏暗：看恒星边缘时，视线斜着穿过的是光球层里更高、更冷的那一层 |
| 模型回复时恒星变亮，其中一个活动区亮一下 | 耀斑：活动区里的磁场突然重联、释放能量。挑的是当时最朝着你的那个活动区 |
| 颜色和大小跟模型的档次走：Haiku 是橙红的小恒星，Sonnet 是黄白的类太阳恒星，Opus 是蓝白的，Fable 最大、最蓝 | 赫罗图的主序：质量越大的恒星越大、越亮、越热，颜色从红（M 型，约 3000 K）经黄白（G 型，约 5800 K）到蓝（B 型、O 型，上万度）。颜色取的是对应温度的黑体颜色 |
| 认不出模型（或者拿不到）时是类太阳的恒星 | G 型是最「普通」的参照 |
| 轨道越外越慢，角速度 ∝ 半径^-1.5 | 开普勒第三定律（周期² ∝ 半径³） |
| 轨道从里往外等比排开，相邻两条半径比 1.5；项目少时行星系就小，不铺满画面。项目多到放不下时比值压小，挤到一定程度改成等距（不然里面几条的名字叠在一起） | 行星轨道大致等比排列（提丢斯-波得定则）：太阳系里相邻两颗行星的半径比在 1.4～1.9 之间。挤的时候改等距是为了看得清，不是物理 |
| 尘埃也按半径转，同一半径同一速度 | 同上 |
| 行星朝恒星的一侧亮，看到的是月相：远侧接近满月，近侧（你和恒星之间）是月牙 | 恒星照亮行星；相位取决于恒星、行星、观察者三者的角度 |
| 发给模型、模型回复的光点：飞行时间和到恒星的距离成正比 | 光速有限 |
| 光点落到恒星上，恒星往外抛一层发光的壳：边缘最亮、往里渐暗、中间一层薄光；恒星挡住后半个壳；越走越慢、越厚越淡，颜色从白热退成铜色 | 日冕物质抛射：抛出的等离子体是一层球壳，视线穿过壳边缘的路程最长，所以边缘最亮（和行星状星云、超新星遗迹是一个道理）；被引力和周围的介质拖着减速；膨胀时冷却 |
| 远处的恒星：暗的远比亮的多；有颜色，越暗越接近白；斜着一条更密、更亮的带。每个星系的天空不一样，同一个星系谁看都一样 | 我们所在星系里的恒星。数量按星等增长（每暗 1 等约多 3 倍）；颜色是光谱型对应的黑体颜色，暗星的颜色人眼分辨不出（暗处靠视杆细胞）；那条带是从银盘里看出去的银河 |
| 远处的恒星在镜头移动、缩放、鼠标视差时都不动；尘埃跟着动 | 它们相对行星系等于在无穷远，视差为零；尘埃在行星系里面 |
| 滚轮放大：镜头往行星系里飞近，恒星、行星随便放多大都清楚；在行星上放大时镜头跟着它公转 | 镜头前移（不是拉长焦距），所以无穷远的星空不变大。东西都是程序画的，不是图片 |
| 自转轴倾斜约 29° | 行星的轴倾角（地球 23.4°） |
| 卫星转到球后面被挡住 | 掩星 |
| 卫星落回时越转越快 | 轨道衰减：半径变小，角速度变大 |
| 子 agent 从射线尖上鼓起、颈部拉细、断开 | 瑞利-普拉托不稳定（液柱断裂成液滴） |
| 子 agent 排在背对恒星的一侧 | 潮汐剥离、L2 点都在背对中心天体的一侧 |
| 尘埃不闪烁 | 同上，闪烁是大气造成的 |
| 射线长度用对数刻度 | 天文学的星等也是对数刻度 |
| 鼠标视差 | 视差 |

## 说得通但牵强的（暂时保留）

- 等你授权时一圈圈的白色波纹：像光回波，但真实的光回波不会周期性重复。
- 在想时沿球边转的珊瑚色彗星：更像极光（恒星的能量打到行星上发光，正好对应「模型在为这个对话干活」），但极光不会绕着转。
- 干活时自转变快：真实世界需要力矩（比如吸积让脉冲星转快），比较牵强。
- 宇宙网随星系数变大、密度不变：这恰好是已被否定的稳态宇宙论（新物质不断产生）。新用户加入必然有新星系出现，所以不改。
- 恒星的大小差别压缩了：真实的 O 型星半径是 M 型红矮星的几十倍、亮度差上百万倍。这里只差一倍左右，否则小的看不见、大的盖住整个行星系。
- 恒星的自转压缩到约 40 秒一圈（真实的太阳 25 天）；米粒放大了几百倍（真实的米粒约 1000 公里，太阳表面上有几百万个），黑子也放大了。
- 黑子的寿命压缩到一两分钟到六七分钟（真实的几天到几个月），活动周期压缩到 20 分钟（真实的约 11 年）。
- 能看清恒星的表面，说明是「近看」；而行星离恒星的距离又是按整个行星系的比例画的。两种尺度画在同一个画面里。
- 断线时一切停转、压暗：类似视界附近看到的时间冻结和红移，作为比喻。
- 项目名「κ Orbis 318」：拜耳命名（希腊字母）和弗兰斯蒂德编号（数字）在真实星名里不会同时出现，Orbis 也不是真实星座。保留为虚构的星名。
